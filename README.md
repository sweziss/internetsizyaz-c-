# WiFi Yazıcı (Android & PC Relay)

Samsung Galaxy A34 5G ve tüm Android cihazlar için geliştirilmiş, WiFi üzerinden bilgisayara bağlı yazıcılara veri aktaran AMOLED siyah temalı yazdırma uygulaması.

---

## 📲 APK İndirme (Doğrudan Yükleme)

GitHub üzerinden APK'yı doğrudan telefonunuza indirmek için:
* **Ana Dizin:** [`WiFiYazici.apk`](./WiFiYazici.apk)
* **Alternatif Klasör:** [`apk/WiFiYazici.apk`](./apk/WiFiYazici.apk)

İndirdikten sonra telefonunuzdan dosyayı açarak kurulum yapabilirsiniz.

---

## 🖥️ PC Köprü Sunucusu (Python)

Bilgisayarınızdaki (Windows, Mac, Linux) yazıcıları telefondan görebilmek için:

1. `pc_print_server.py` dosyasını çalıştırın:
```bash
python pc_print_server.py
```
2. Uygulamadan **"Ağda PC Ara"** seçeneğine dokunun veya görünen IP adresini girin.
3. Belge, fotoğraf veya notlarınızı doğrudan yazdırın!
